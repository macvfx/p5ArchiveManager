# P5 Archive Manager API 4.2.1 (build 43) — pre-release beta

**Status:** pre-release · **Date:** 2026-09-22 · **Tag:** `4.2.1+43`

A small release on top of 4.2.0: the app now tells you what is new in it.

## Headline: What's New, in the app

- **Help ▸ What's New…** shows the release notes for every version, newest first.
- Each release's **headline feature** sits on a highlighted card above its smaller changes,
  badged **NEW** while it belongs to the current release line. For 4.2 that is **Restore
  from Project File** — see the [4.2.0 release notes](API-V4.2-RELEASE-NOTES.md).
- The window **opens once by itself after an update**, so a new feature is not missed. A
  first install gets the welcome guide instead.
- The **Help** window opens with a *What's New* card listing the current headlines, and
  marks the restore entries **NEW**.

Nothing else changed: the restore, check, delete and archive workflows are as in 4.2.0,
and the same cautions apply — test **Restore into a folder** before restoring to the
original location.
